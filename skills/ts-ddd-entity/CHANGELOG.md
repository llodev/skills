## 0.2.0

### Minor Changes

- [#113](https://github.com/llodev/skills/pull/113) [`84d55a5`](https://github.com/llodev/skills/commit/84d55a51920df1359294676e7d64989717a9cf0f) Thanks [@lloliveiradev](https://github.com/lloliveiradev)! - Node 24 floor and self-contained published content.

  - Published skill content no longer points at files that only exist in this repository: the broken lifecycle design link in pm-tasks-core is gone, the internal lint contract moved out of `references/` into the repo docs, and internal roadmap codes and version promises were removed from pm-tasks-jira.
  - The ts-ddd family and ts-query-cqrs read as general TypeScript + DDD guidance: no "this repo" wording, origin-project paths or aliases; example layouts, aliases and the sample `Celebration` domain are labelled as examples to adapt, and stack-specific advice (NestJS, Firestore, Prisma) is framed conditionally.

## 0.1.0

### Minor Changes

- [#64](https://github.com/llodev/skills/pull/64) [`97be3af`](https://github.com/llodev/skills/commit/97be3af54e68a459cf9ba064b800dc26c5bd141d) Thanks [@lloliveiradev](https://github.com/lloliveiradev)! - feat(ts-ddd): first release of the TypeScript + DDD design skill family

  New `@llodev/ts-ddd-*` family — 8 project-agnostic guide skills (entity,
  value-object, dto, use-case, repository, controller, domain-service, and
  read-side `ts-query-cqrs`) plus the `@llodev/ts-ddd` meta-package that
  installs them all. Generalized from a private monorepo to the `@acme/`
  placeholder convention; each ships README (en/pt-BR/es-ES), references,
  and worked examples. No MCP, no runtime — pure knowledge skills.

Release history is generated by [Changesets](https://github.com/changesets/changesets) on `changeset version`. The first entry (`0.1.0`) lands when this package is first released; until then the pending change lives in `.changeset/`.
