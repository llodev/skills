# Sources that are not plain text

Trust what you can actually read. Do not switch tools after one readable rendering.

| You have | Trust |
| --- | --- |
| Text, cells, speaker notes, or a saved notebook output | That text. Do not re-run a notebook, a query, or a script to manufacture a new number |
| A picture, scan, or chart with no text layer | Only labels visible after you open or render it. If a cell stays unreadable, write that it is unreadable and name the page. Do not guess the cell |
| A cited figure whose text extraction is empty | Render that page only. Transcribe the visible labels. Stop once the page is readable |
| Slides | Slide text and speaker notes. If the point exists only in the picture, open the picture |
| A spreadsheet | The labels and the cells that are there. Do not add an analysis the sheet does not contain |
| Code | What the code does, in sentences. Do not paste the file into the abstract |
| Audio or video with a transcript | The transcript |
| Audio or video with no transcript | Stop. Tell the user there is nothing to abstract. Do not summarize the title, the filename, or a guess about the content |

A broken extraction token (`10 120` where a power was printed) stays as the tokens you saw. If you also give the usual reading, label it as a reading.
