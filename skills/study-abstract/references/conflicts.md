# Stacked conflicts

Apply every matching row from the skill. This file is the case where more than one row matches, and the case where one correction note covers a set.

## Two rows, one passage

A figure groups item 6 with B. The table on the same page labels item 6 as A, with a positive output. The page also reports 94.7% accuracy from one hold-out.

Write both groupings, and say which sentence is the figure and which is the table. Do not pick the table because it has numbers, and do not "fix" the figure so they agree. Mark 94.7% as a single run, in the output language. The grouping conflict and the single-run label are both required. Applying only the first match drops the second.

## A correction note for the whole set

A file beside the set that corrects several units is not a unit and not a paragraph to paste into every abstract.

1. Split the note by the unit it names.
2. In that unit's abstract, write the source sentence and the correction as two labeled sentences.
3. Copy a formula the note actually writes. Do not add the algebraic link from memory if the note does not write it.
4. Point at the note from Title and source.
5. Leave the other units alone. A correction of unit 4 does not belong in unit 1.

## Do not finish a broken example

When the printed example contradicts its own definition, quote the definition and quote the printed example. The successor pair that repeats the origin is done when both are on the page. Completing the pair with the state you think was meant replaces the source with a guess.
