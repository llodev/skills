# Index

Read this only when writing the index of a set. Do not read it for one unit or for a mixed folder. Do not turn the index into a second copy of the abstracts.

```markdown
# <Set title>

| Unit | Question it answers |
| --- | --- |
| <unit title, linked> | <one question, in the output language> |

## How the units relate

<One sequence diagram, only if the source itself orders the units. Otherwise omit this heading.>
```

The question column is the reason to open that unit, not a list of its terms. If the source does not order the units, the table is the whole index.
