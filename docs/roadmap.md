## 8. Risks

| Risk                                                                           | Mitigation                                                                                                                       |
| ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| A tool's MCP goes down or changes contract                                     | E2E canary (v1.5.0) covers tarball install + smoke. Add live-MCP smoke per adapter as F15-adjacent work                          |
| Tarball size explodes with N adapters × M locales                              | Tarball snapshot test (v1.2.1) catches drift; size-limit gate (R5 in §2.2) makes the budget explicit                             |
| Verb surface grows past `task.move` (7) → harder to audit autonomous allowlist | `crud-vocabulary.md` is canonical; each new verb goes through `contract-check` Phase A; allowlist in `.tool.json` stays explicit |
| Skill-judge baseline drifts as the rubric evolves                              | Golden master (E2 in §2.1) snapshots rubric input next to score                                                                  |
