# @llodev/skills — Roadmap

Date: 2026-06-26. Baseline: `main` at v1.10.0 (canary publish; PRs #22–#25 merged). Forward-looking roadmap — single source of truth for **what's next**. Per-package `CHANGELOG.md` (auto-generated by Changesets) is the canonical history; this doc stays focused on the future.

## 8. Risks

| Risk                                                                           | Mitigation                                                                                                                                         |
| ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| A tool's MCP goes down or changes contract                                     | E2E canary covers tarball install + smoke against real npm (canary publish, v1.10.0). Add a live-MCP smoke per adapter alongside each new adapter. |
| Tarball size explodes with N adapters × M locales                              | Tarball snapshot test (v1.2.1) catches drift; size-limit gate (shipped v1.7.0) makes the budget explicit                                           |
| Verb surface grows past `task.move` (7) → harder to audit autonomous allowlist | `crud-vocabulary.md` is canonical; each new verb goes through `contract-check` Phase A; allowlist in `.tool.json` stays explicit                   |
| Skill-judge baseline drifts as the rubric evolves                              | Rubric golden master + drift gate (shipped v1.7.0) snapshots rubric input next to score                                                            |
