# @llodev/skills — Roadmap

Date: 2026-06-19. Baseline: `main` at commit `74ff97a` (v1.8.0 merged via PR #18). Forward-looking roadmap — single source of truth for **what's next**. Per-package `CHANGELOG.md` (auto-generated by Changesets) is the canonical history; this doc stays focused on the future.

## 3. Next P0 candidates (pick one)

Platform hardening before scaling to more adapters. Recommended order: **E → F → start §4 from v1.11.0**.

| Option                                                                 | Bundle                                                                                                           | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Target  |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| **E — Platform: headless runtime + plan-execution mode (recommended)** | F14 (headless `@llodev/pm-tasks-<tool>/adapter`) + F15 (agent-agnostic plan-execution mode in `pm-tasks-<tool>`) | F14 makes every new adapter callable from code without activating the full skill flow. F15 turns the skill itself into the recommended entry point for "execute this plan against my pm-tasks tool" — agent-agnostic and IDE-agnostic. We don't try to build adapters for every coding skill (over-scope and brittle); instead the skill, when invoked, owns: (1) verifying `.<tool>.json`, (2) probing for existing tasks for the plan and prompting creation if missing, (3) executing via whatever code-execution strategy the agent is using, (4) auto-updating checklists / comments at task boundaries. | v1.9.0  |
| **F — Canary publish**                                                 | R4 (`0.0.0-pr-<n>` publish on PR) + extend E2E canary to install from the canary tarball                         | Publish surface grows linearly with adapter count. Canary tarball + real npm semantics catch what local `pnpm pack` can't (lessons from v1.0.1).                                                                                                                                                                                                                                                                                                                                                                                                                                                              | v1.10.0 |

Once Options E and F ship, adapter expansion (§4) starts from v1.11.0.
